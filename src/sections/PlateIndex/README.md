# PlateIndex — THE OLD/MODERN COLLISION

The flagship proof section: four antique ink-wash plates framed by aggressively
contemporary print-production language.

- **OLD** — the ink-wash plates stay exactly as antique as they are (sepia /
  charcoal wash on warm paper), never modernised.
- **MODERN** — brutalist display grotesk (Cabinet 800, huge, tight tracking),
  mono micro-labels, tabular numerals, hairline rules.
- **BRIDGE** — print language belongs to both eras and therefore neither:
  plate numbers (PL. I–IV), registration crosses, crop marks, ink specs, paper
  stock, folio footers.

Lime appears only as a FILL with ink type on top (the single allowed lime-on-
light use). Reveals are transform/opacity only. All copy and image paths come
in as props from `config/site.ts`.
